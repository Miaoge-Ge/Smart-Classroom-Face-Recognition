# 智慧课堂人脸识别考勤系统 — 5分钟演示录屏脚本

## 录制前准备

1. **环境确认**：`start.bat` 能正常启动，浏览器能打开 `http://127.0.0.1:8000`
2. **人脸预注册**：提前将4位室友的人脸通过学生管理页面注册好，录屏时只需展示已注册列表
3. **模拟教室合影**：用手机拍一张4人坐在一起的合影照片，放到 `test/` 目录下
4. **关闭无关窗口**：通知弹窗、浏览器书签栏、多余标签页全部关掉
5. **录屏工具**：推荐 Windows 自带 Xbox Game Bar（Win+Alt+R），或 OBS
6. **打开要展示的文件**：提前在 VS Code / 编辑器里打开 `services/face_service.py`、`web/app.py`、`test/test.py`、`models/backbones/nexnet.py`

## 实操要点

1. **段落3.3（实时识别）是重头戏**，时间上要留够，确保4张人脸都出现在画面中并被识别
2. **摄像头提前调试好位置**，让4人能同时入镜且人脸清晰（建议笔记本垫高，人坐稍远处）
3. **宿舍光线**：开灯、拉开窗帘，避免背光。如果识别率不稳定，提前在设置页把相似度阈值从 0.75 降到 0.6
4. **讲解和画面要对上**：鼠标指哪里讲哪里，不要画面不动光讲
5. **如果某段超时**：优先压缩段落1（架构）和段落4（测试脚本），保住段落3.3（实时识别）
6. **录屏前试跑一遍**：完整走一遍流程，掐表看时间，调整语速
